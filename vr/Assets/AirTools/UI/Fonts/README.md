# Fonts

`Inter-Regular.ttf`, `Inter-Medium.ttf`, `Inter-SemiBold.ttf` — Inter 4.1 by the Inter Project Authors
(https://github.com/rsms/inter, release `Inter-4.1.zip`, sha256 9883fdd4…b11e, `extras/ttf/`). Licensed under the
SIL Open Font License 1.1: see `Inter-OFL.txt` (ship it with any build you distribute).

`Inter-* SDF.asset` are generated from them by **AirTools ▸ Build UI Assets** (one static 1024² atlas per weight:
Latin + the symbols the app prints, LiberationSans fallback). Use only these three weights (design system,
docs/UI.md).
